# news-image-20261124

Entry for make.fun's news-image-20261124 competition: a Python script that copies the poster `assets/entry.png` into the output directory (`$MAKEFUN_OUTPUT_DIR`, default `/output`).

Run with `python3 main.py` (optionally `MAKEFUN_OUTPUT_DIR=out python3 main.py`).
Standard library only, Python 3.13, no network.
